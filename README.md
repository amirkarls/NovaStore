# NovaStore

Hello! That's my buggy project — **NovaStore** app. Artificial intelligence was used to correct many errors.

---

## What is NovaStore?

NovaStore is an open-source Android app store. It collects direct download links from **F-Droid** and **GitHub Releases**, so you can install and update open-source apps without Google Play.

## Features

- **70+ apps** in the catalog: media, games, security, development, communication, tools
- **Direct APK download** from F-Droid and GitHub
- **Version picker** — choose any release from GitHub
- **Install & update** via system package installer
- **Material You** support with dynamic colors
- **6 accent colors** if Material You is off
- **5 languages**: Russian, English, Ukrainian, Kazakh, Spanish
- **GitHub token** support (optional) — for higher API limits

## Language warning

All languages except Russian and English were translated by machine translation and may contain errors.

## Install

1. Go to **Releases**.
2. Download the latest `.apk`.
3. Install it on your Android device (allow installation from unknown sources).

## Requirements

- Android 8.0 (API 26) or newer
- Internet connection for downloading apps
- (Optional) GitHub token for higher API limits

## Build

APK is built automatically via **GitHub Actions** on every push to `main`.
